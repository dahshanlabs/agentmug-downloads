# AgentMug Desktop downloads

This repository is the public download channel for official AgentMug Desktop builds.

- Product: https://agentmug.com
- Portable open core: engineering audit complete; publication awaits ownership, trademark, and counsel release approval
- CLI: `npm install -g @agentmug/cli`

## Security notice

The current desktop installers are not yet code-signed. Windows and macOS may show an unknown-publisher or unidentified-developer warning. Verify the SHA-256 checksums attached to each release before installation.

The official AgentMug name, Mughead character, logos, and other Dahshan Labs brand assets are not licensed for redistribution. This repository distributes release artifacts; it is not the AgentMug source repository.
